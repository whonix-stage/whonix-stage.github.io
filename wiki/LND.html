Installing and verifying LND (Lightning Network Daemon) in Whonix.

LND is the Lightning Network Daemon by Lightning Labs, an implementation of a Lightning Network node.

1 Download the release, the manifest and the signatures.

LND releases on the releases page ship a manifest file manifest-.txt (the SHA-256 hashes of every release binary) together with one detached signature per maintainer, named manifest--.sig. The release is signed by multiple maintainers; verifying several independent signatures is stronger than relying on a single key.

2 Retrieve and verify the signing keys.

Unlike a single-key project, LND publishes the maintainer signing keys inside the source repository, under scripts/keys/ (one .asc per maintainer, e.g. roasbeef.asc). Retrieve the keys from there. [1]

3 Verify the manifest signatures.

Verify each maintainer signature against the manifest, for example with Sequoia:

sqv --keyring <all-maintainer-keys> manifest-<maintainer>-<version>.sig manifest-<version>.txt

or with GnuPG after importing the keys:

gpg --verify manifest-<maintainer>-<version>.sig manifest-<version>.txt

A release should be accepted only if a quorum of independent maintainer signatures verifies. At the time of writing, release v0.21.0-beta carried five maintainer signatures (roasbeef, hieblmi, suheb, yyforyongyu, ziggie1984), all of which verify against the in-repository keys.

4 Verify the downloaded binary against the manifest.

Once the manifest signatures are verified, confirm the downloaded archive matches the hash in the manifest:

sha256sum --check --ignore-missing manifest-<version>.txt

The expected output for the downloaded archive is OK.
