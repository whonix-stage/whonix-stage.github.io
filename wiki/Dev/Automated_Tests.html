relevant links

The tests ideally would be aware of which boot mode (normal, recovery, future others) it would boot in and which virtual terminal it would run the test in. Maybe that could be an abstraction.

Some tests are virtualizer-specific. Many tests will function in Qubes-Whonix (such as Tor Browser tests), but shared folder tests differ for VBox / KVM. Virtualization can be detected using systemd-detect-virt.
