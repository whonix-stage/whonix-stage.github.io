Introduction

It is safe to run sudo apt autoremove so long as the specific Whonix machine meta package is kept for the Non-Qubes-Whonix or Qubes-Whonix platform. In other words, these packages should not be in the list of autoremoved packages.

Platform specific. Select your platform.

Non-Qubes-Whonix LXQt

  • 18:
    • Whonix-Gateway 18: whonix-gateway-vm-gui-lxqt
    • Whonix-Workstation 18: whonix-workstation-vm-gui-lxqt

Qubes-Whonix

  • 18:
    • Whonix-Gateway 18: whonix-gateway-qubes-gui-lxqt
    • Whonix-Workstation 18: whonix-workstation-qubes-gui-lxqt

It is actually a good idea to safely run sudo apt autoremove according to the following instructions on this wiki page to make sure extraneous packages which might no longer be recommended for default installation are removed.

Re-install Meta Packages and Safely Run Autoremove

1. Update the package lists.

sudo apt update

2. Ensure a proper meta package is installed. [1]

Platform specific. Select your platform.

Non-Qubes-Whonix LXQt

  • 18:
    • 18: Whonix-Gateway: sudo apt install whonix-gateway-vm-gui-lxqt
    • 18: Whonix-Workstation: sudo apt install whonix-workstation-vm-gui-lxqt

Qubes-Whonix

  • 18:
    • 18: Whonix-Gateway: sudo apt install whonix-gateway-qubes-gui-lxqt
    • 18: Whonix-Workstation: sudo apt install whonix-workstation-qubes-gui-lxqt

3. Auto remove packages.

sudo apt autoremove

4. Reconfirm a proper meta package is still installed.

Repeat step two.

5. Done.

The procedure of safely running sudo apt autoremove is complete.
