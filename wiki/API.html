Detecting Whonix version number using API.

API Stability

There is no API version number and not even non-binding guarantees about API stability are being made.

For example for the VirtualBox stable version number Whonix, Template:VersionNew was used earlier anyhow prior any request for any API functions has been made. Making that version information available through an easy to parse way is pretty simple thanks to mediawiki index.php already built-in function action=raw.

API Completeness

Other information might be already available (since the wiki or forum software has these features anyhow). Please ask in forums.
