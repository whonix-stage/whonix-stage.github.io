Whonix News and Security Advisories

To stay safe and informed, users should follow official Whonix news, especially the Important News category.

Important News is used for critical announcements such as security advisories, possible upgrade issues, and important stable releases.

Whonix News

There are several ways to receive Whonix news.

1 Choose What to Follow

Users with limited time should follow at least Important News. Users who want more detail can follow All News. All News includes Important News.

2 Choose How to Receive It

The same news can be received through different delivery methods, such as the forum website, RSS, e-mail, or Telegram.

3 Do Not Rely on Social Media Only

Social media posts may be delayed, incomplete, or not posted to every platform. Do not rely on social media as the only source for important Whonix news.

4 Select deliver method.

All News

All News includes Important News plus general project updates.

This may include testing announcements, development news, new features, future plans, calls for testing, updated documentation, and other project news.

All News is useful for users who want to follow Whonix development more closely.

Telegram is another delivery method for news updates.

Whonix Telegram News Channel

Do not rely on Telegram as the only source for important news.

Social Media

Copy or share this direct link!https://www.whonix.org/wiki/Stay_Tuned#Social_MediaForum (BBCode)[url=https://www.whonix.org/wiki/Stay_Tuned#Social_Media]Social Media[/url]

There are some Official Whonix Social Media Profiles online.

Do not rely on social media for the latest Whonix news or for urgent security information. Social media posts may be delayed, incomplete, or not posted to every platform.

Some messages from the Whonix Feature Blog are also posted on:

  • Whonix Telegram News Channel
  • Whonix Twitter Profile
  • Whonix Facebook Profile

However, social media should not be treated as a complete or reliable news source.

If it is safe to inform others about Whonix, users can Contribute by sharing official news through an anonymous account.

Source Code

Copy or share this direct link!https://www.whonix.org/wiki/Stay_Tuned#Source_CodeForum (BBCode)[url=https://www.whonix.org/wiki/Stay_Tuned#Source_Code]Source Code[/url]

Users interested in Whonix source code updates can subscribe to code changes.

Source code updates are for users who want to follow development at the code level. They are not a replacement for Important News or All News.

Reason

Security and software issues sometimes require quick action from users. For example, users may need to update immediately, avoid a broken update, or temporarily stop using a feature until a fix is available.

Following official Whonix news helps users receive these warnings in time.

Debian Security Announcements

Since Whonix is based on Debian, users should consider subscribing to the Debian security announcement mailing list to stay informed about Debian security advisories.

See also: Debian Security Announcements.

Operating System Updates

It is important to regularly check for operating system updates on the host operating system and all virtual machines (VM).
