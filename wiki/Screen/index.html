Screen Resolution, DPI (dots per inch), Full Screen, Tor Browser window size (maximization?)

Recommended Screen Resolution

  • Recommended: Use screen resolution 1920x1080.
  • Rationale: See forum discussion: Make screen resolution 1920x1080 by default for all VMs

Default Screen Resolution

  • Note: Default screen resolution is platform specific.
  • Non-Qubes-Whonix: VirtualBox and KVM use 1920x1080 by default.
  • Qubes-Whonix: Depends on dom0.

Full Screen Recommendation

  • Note: Full screen recommendation is platform specific.
  • Non-Qubes-Whonix: Virtualizers VirtualBox and KVM do not use full screen by default. It is recommended to use Use Full-screen Mode.
  • Qubes-Whonix: Uses full screen by default. Avoid VM Full Screen Mode is discouraged.

Tor Browser Window Size

  • Avoid: Maximize or resize the Tor Browser window.
  • Rationale: See browser window size.
  • Keep: Default window size.

DPI

  • Avoid: Change DPI settings.
  • Keep: Default DPI settings.

Custom Settings

  • Question: Do custom settings negatively affect anonymity?
  • Note: This is unspecific to Whonix.
  • Note: This depends on Tor Browser. Therefore this question is best redirected to Tor Browser as per Self Support First Policy.
  • Recommendation: For abundance of caution, reasonable default settings are recommended on this page.
  • Forum discussion: Will custom dpi (dots per inch) values negatively affect my anonymity?
